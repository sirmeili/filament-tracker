The phone layout for Inventory: bottom bar (Menu · Scan · account), search and Filter, quick filters, compact rows that expand when tapped, the filter sheet, the menu and the Account page. Everything here works: tap around. Links to pages that are not in this file show a note instead. Sample data is made up.

Built from the four .dc.html mockups in this folder (docs/mockups/mobile-web). Fonts load from Google Fonts when online; offline the page falls back to system fonts.
